Expense Tracker

An efficient mobile application for tracking and managing expenses with powerful analytics and notifications for each use case, supporting both manual entry and automated extraction from PhonePe transaction screenshots.



Overview:

This application helps users log, categorize, and analyze their expenses quickly and intuitively. Users can either upload images (such as transaction screenshots) or manually enter their expenses. The app visualizes spending patterns, supports budgeting, and provides helpful analytics. Notifications are delivered on-time based on analytics, usage scenario, and other use cases.



Features:
- Screenshot Expense Entry: Upload and scan PhonePe transaction screenshots directly from your device or screenshot buffer for rapid expense capture.
- Manual Entry: Add expenses by hand, including payee, amount, notes, and category selection.
- Categorization: Organize spending by category and track where your money goes.
- Budgeting: Set custom budget limits for categories to monitor and control your spending.
- Analytics Dashboard: Visualize spending trends and category-based summaries.
- Optimized for PhonePe: Automated data extraction is tailored specifically for PhonePe screenshots.
- Notifications: Set-up for multiple categories of usage and can be turned off if needed.
- OCR: Powerful Image pre-processing along with normalization guarantees 70% success rate. 




Compatibility & Limitations:
- OCR Compatibility: The automatic extraction feature for PhonePe transaction screenshots(Screenshots taken of the transaction page in history tab) works on any device but has to be customised in crop selection exactly making sure only name and amount is visible.
- Platform: Currently supports PhonePe auto-parsing only; more platforms and broader OCR support are planned for future versions.
- Feedback & Bugs: The app is actively maintained and may have bugs. User feedback and bug reports are highly appreciated and will help guide further improvements.
- 50% of the screens arent actively visible and are hidden under Long-press and Upward swipes. So ensure to properly check and reachout for doubts.
